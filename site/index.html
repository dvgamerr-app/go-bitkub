Running in under a minute.

Pick the install that fits your machine, then read the market straight away. Keys are only for your own account.

  1. Install the CLI

    One go install, or a prebuilt binary from the latest release.

  2. Read the market

    bitkub market ticker btc_thb works with no account and no configuration.

  3. Connect your account

    Export BTK_APIKEY and BTK_SECRET, or put them in a .env file, to unlock balances, orders and transfers.

# Go 1.26 or newer
$ go install github.com/dvgamerr-app/go-bitkub/cmd/bitkub@latest
$ bitkub market ticker btc_thb
# x86_64; use Linux_arm64 on ARM
$ curl -fsSL https://github.com/dvgamerr-app/go-bitkub/releases/latest/download/go-bitkub_Linux_x86_64.tar.gz | tar -xz bitkub
$ sudo mv bitkub /usr/local/bin/
$ bitkub market ticker btc_thb
# Apple silicon; use Darwin_x86_64 on Intel
$ curl -fsSL https://github.com/dvgamerr-app/go-bitkub/releases/latest/download/go-bitkub_Darwin_arm64.tar.gz | tar -xz bitkub
$ sudo mv bitkub /usr/local/bin/
$ bitkub market ticker btc_thb
# PowerShell
> Invoke-WebRequest https://github.com/dvgamerr-app/go-bitkub/releases/latest/download/go-bitkub_Windows_x86_64.zip -OutFile bitkub.zip
> Expand-Archive bitkub.zip -DestinationPath "$env:USERPROFILE\bitkub"
> $env:PATH += ";$env:USERPROFILE\bitkub"
> bitkub market ticker btc_thb

Full options, PATH setup and uninstalling: install guide.

Or call it from Go.

Import a package per API area. Public calls work immediately; bitkub.Initlizer() reads your keys from the environment for everything else.

go get github.com/dvgamerr-app/go-bitkub

Every function with an example is in the SDK reference. Streams are covered in the stream guide.

tickers, err := market.GetTicker("btc_thb")
if err != nil {
	log.Fatal(err)
}
fmt.Printf("BTC/THB %.2f\n", tickers[0].Last)

// reads BTK_APIKEY and BTK_SECRET
bitkub.Initlizer()
balances, err := market.GetBalances()

s := stream.New(nil)
s.ConnectMarket("market.ticker.thb_btc")
for msg := range s.Messages() {
	fmt.Println(msg.Type, msg.Data)
}
